## 二、平台与安全要求对照（提示词 §5.1/§15）

| 要求 | 状态 | 说明 |
|---|---|---|
| 完全本地运行 | ✅ 设计保证 | 无任何网络代码；无遥测 |
| 不上传用户文件 | ✅ 设计保证 | 全部读写限于 App 沙盒 Documents/Projects/ |

## 四、暂不实现/受限项（公开说明）

| 项 | 标签 | 原因 |
|---|---|---|
| Ghidra 级反编译（真 C 伪代码） | ⛔ | 需要 JVM/桌面运行时，iOS 沙盒不可能；以 Capstone 反汇编+近似伪代码替代 |
| ObjC 类/方法结构树 | 📋 v1.1 | 需要 dyld chained fixups 指针解码，MachOKit API 已具备，下一版实现 |
| 指令级交叉引用 | 📋 v1.2 | 需全量反汇编+地址索引，规划中 |
| App Store 加密包完整分析 | ⛔ | cryptid=1 的包文件态为密文；仅分析明文部分，不解密（合规边界） |
| 模拟器 | 📋 | 非核心需求，暂缓 |
