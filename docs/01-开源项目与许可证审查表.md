## 四、原版代码复用记录（提示词 §2.3 要求）

- 本 App 的核心引擎全部来自上表三个成熟开源项目的真实代码，未重写任何已被覆盖的功能。
- 我们自研的模块层（均为上游未覆盖、必须新增的部分）：
  1. `ObjCMetadataService`——普通 IPA 二进制的 ObjC 命名数据提取（MachOKit 的 ObjC API 面向 dyld cache 场景）；v1.1 将通过 MachOKit 的 DyldChainedFixups API 增加结构化类/方法树
  2. `MachOService.scanStrings`——分块字符串扫描（性能档位分块/上限/取消是平台适配层职责）
  3. `DisasmService.pseudocode`——近似伪代码视图（无可移植的成熟 ARM64 反编译引擎，见验证报告）
  4. 性能管理/兼容性检测/项目管理/检查点恢复——iOS 沙盒平台适配层
- 每处修改与新增原因均记录于《功能清单与移植对照表》。
